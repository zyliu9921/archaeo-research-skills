# 文献精读笔记（Obsidian）

把一篇已转成 Markdown 的文献写成一份结构统一、可被 Obsidian 正常识别的笔记。目标不是摘要，而是可复核的读书记录：论点要能回到原文位置，评价要给出理由，延伸阅读要指向本文真正引用过的文献。

## 一、准备

1. 拿到该文献的 Markdown 全文（见 `mineru-pdf-to-markdown`）与原始 PDF。
2. 确认题录：作者、篇名、刊名、年份、期次、页码。
   - **核准顺序**：PDF 首页页眉／版权页 → DOI／CSTR → CNKI／万方／期刊官网 → 仍无则写「原文未标注」。
   - **不要相信文件名里的年份**：Zotero 等工具导出的文件名常与正式出版年差一年。
   - 期次写法：`2025年第2期`；有卷号可写「第 2 卷第 2 期」但 YAML 里只保留「年份年第X期」。
3. 决定文件名：**只用篇名**，不加作者与年份。Windows 非法字符 `\ / : * ? " < > |` 换成全角 `？` 等；篇名过长可截断但要保留可辨识部分。
4. 决定标题语言：中文刊用中文篇名；外文刊用原文篇名，并另存 `original-title`。

## 二、八节结构

模板见 `assets/obsidian-template.md`。八节固定顺序、固定编号，不得增删：

| 节 | 要求 |
|---|---|
| 1. 基本信息 | 作者（含单位）、年份、来源（引文 + 题录核准说明）、关键词 |
| 2. 研究问题 | 引用块写主问题（一句话），下接 3—4 个子问题，最后一条写「为什么值得研究」 |
| 3. 核心观点 | 引用块写 1—3 句总论点，下接 3—5 条要点，每条加粗小标题 |
| 4. 论证与证据 | `### 主要论点 1/2/3` 各含论据；`### 关键证据 / 方法` 列 3 条数据、图号、表格或方法步骤 |
| 5. 我的评价 | 贡献、局限、我是否认同（必须给理由，可唱反调） |
| 6. 对我的启示 | 与自己的研究／写作的具体关联，不写「很有启发」这类空话 |
| 7. 重要摘录 | 2—4 段原文关键句 + 位置标注 |
| 8. 延伸阅读 | 3 条，见下节 |

结尾两行：

```
**阅读日期：** 2026-01-01
**阅读状态：** #待整理
```

`阅读状态` 是字段名，值写成标签。标签值由使用者的 vault 约定决定，常见 `#待整理`、`#阅读情况：待整理`。校验脚本用 `--status-tag` 匹配。

## 三、第 8 节「延伸阅读」

**只从本文自己的参考文献／注释里选**，不从自己的文献库里另挑。理由：这份笔记的用途是把一篇文献锚进学术脉络，读者需要看到作者本人承认的对话对象。

每条格式：

```
- 作者：《篇名》，《刊名》年份年第X期。（选读原因：一句话说明与本文的具体关系）
```

- 引文按 `kaogu-citation-format` 的《考古》体例写（其他刊物投稿时替换成该刊体例）。
- 括号内写**具体关联**：「用同一批遗址的陶片重新排了分期」，而不是「相关研究」「可参考」。
- 被引文献恰好在自己的库里时，可写成 `[[笔记名|引文]]（选读原因：…）`，Obsidian 里可直接跳转；不在库里就不加双链，**不要为了凑链接而编造笔记名**。
- 年份、期次、页码必须能从原 PDF 参考文献段核到；核不到就换一条文献，不要猜。

## 四、写完之后必做

```bash
python scripts/check_notes.py --notes-dir "我的库/笔记" --status-tag "#待整理"
```

检查项：frontmatter 可解析且六键齐全、只有一个 H1 且与 `title` 一致、八节齐全、`type` 在五类内、`sitation` 加引号且合体例、`来源` 含《刊名》、延伸阅读 3 条合格式、双链目标都存在、无残留占位符。

输出末行 `COUNT=n BAD=m`；`m>0` 时逐条看 `errors` 与 `failed`。

附 PowerShell 版 `scripts/check_notes.ps1`（同样参数，`-NotesDir` / `-StatusTag`），适合没有 Python 的 Windows 环境。

## 五、内容红线

1. **页码**：源 Markdown 通常没有页码。要么用 `pdftotext -f <页> -l <页>` 核对后写真实页码，要么写「所在章节：3.2 遗址分布」，**不许编造页码**。
2. **数字**：MinerU 对中文排版 PDF 常整片丢数字。凡引用遗址数量、百分比、测年值，先用原 PDF 复核；核不到就在笔记里标注「原文该处数据在转换中丢失」。
3. **引文**：摘录必须逐字，改字、并句、补主语都算篡改。
4. **评价**：写「局限」要有依据（样本、方法、推论跨度），不是礼貌性客套。

## 六、边界

- 本 skill 只管单篇笔记的结构与规范，不做文献综述、不做多篇比较。
- 笔记里的判断是读者的判断，不是作者的主张；两者在文中要能分清（作者观点放第 3 节，自己的评价放第 5 节）。
