# 学术与考古学文献翻译规范

本 skill 规定学术文献（尤其考古学）翻译中专有名词的处理原则与行文要求。目标是让地名、遗址名、器物名、学科术语译得准确，且译文读起来像中文母语者写的。

## 何时使用

- 任何翻译任务，只要涉及学术／考古学内容（论文、外文文献、报告、书籍章节）
- 任何需要翻译或确认地名、遗址名、器物名、考古术语的场合
- 英译中时，产出应符合学界通用译名，而非逐字硬译

不适用：纯文学翻译；不涉及专有名词的日常文本。

## 核心原则

### 1. 术语优先

翻译学术文献时，以下三类词必须译准，优先于行文流畅度：

1. **地名** 2. **遗址名** 3. **器物名**

宁可句子稍显生硬，也不能译错名词。专有名词错了，整篇翻译就不可靠。

### 2. 先查术语库

`references/glossary.md` 是必读的活文档。部分英文词在考古学中已有约定译法，不得按常见词义翻译：

- `household` → **家户**（不是"家庭""住户"）
- `interpret` → **阐释**（不是"解释"）
- 其余条目见术语库，遇到新词先搜索确认再定译

**学者独创词与跨学科借用词**：凡是学者独创、或从其他学科引入考古学的术语（如 `feasting` → 宴飨、`chiefdom` → 酋邦、`heterarchy`），即使译名已确定，也应在译名后括号标注原词，方便读者溯源。格式：`宴飨(feasting)`。

术语库每条都带「依据」栏，值有三类：

| 依据 | 含义 | 用法 |
|---|---|---|
| **有出处** | 可回溯的文献、工具书或机构译名表 | 可直接采用 |
| **通行** | 中文学界常用译法，但未逐条追到最初出处 | 采用，遇到强反例再议 |
| **待核实** | 尚未找到可靠出处 | 译后加注原文，并在文末说明 |

「待核实」不是耻辱，编一个出处才是问题。

### 3. 遗址名处理规则

**中国遗址名（出现在外文文献中）：**
- 外文多为拼音转写，必须**上网查证对应的中文原名**，不得凭拼音猜测（拼音可能有歧义，或已改用标准名）
- 例：`Dadiwan` → 大地湾，`Yuchisi` → 尉迟寺，`Jiangzhai` → 姜寨
- 查不到权威来源时，写 `待核实（原文: Dadiwan）`，不要给一个看起来合理的名字

**外国遗址名：**
- 先按翻译学界的地名翻译惯例给出译名
- **必须在译名后用括号附上外文原名**，方便读者对照检索
- 例：耶利哥(Jericho)、摩亨佐-达罗(Mohenjo-daro)

### 4. 保留原文的专有名词

部分专有名词（尤其是拉丁语／法语源学术短语、学界通用而难译的术语）依学界惯例**直接保留原文，不作翻译**，译文与注释中均不得强行翻译：

- `de facto refuse`（考古学专有名词，指毁灭情境下原位保留、未经清理的生活遗物）→ 保留原文
- 其他此类词，翻译前先确认是否已有通行译名；无通行译名且学界惯用原文者，保留原文，并在"翻译说明"中说明

注意区分：这不同于第 3 节的"待核实"——保留原文是**有意为之**，不是不会译。仍应在译注中说明该词含义。

### 5. 不确定时的处理

凡是不能确定译名的词（器物、遗址、术语），一律采用：

```
约定译名(原文: xxx)
```

即在译文后括号中保留原词。宁可用"原词 + 注释"，也绝不硬译、猜译。

### 6. 行文规范（去翻译腔）

术语准是底线，行文也要像中文母语者写出来的。翻译须遵循：

1. **拆解英文式长定语**：英文常见的多重定语从句（如 "a dwelling preserved well in a destruction stratum and excavated at Tel Halif"）不得直译为中文长定语堆叠，应拆成若干短句：
   - 直译腔："对一处保存于毁灭层中、出土于泰尔·哈利夫的柱式住宅内既存遗物所进行的空间分析"
   - 改译："作者对一处柱式住宅的 de facto refuse 作了空间分析。该住宅保存完好，出自一处毁灭层，发掘于泰尔·哈利夫。"
2. **避免"一逗到底"的复合长句**：英文常以 and/but/then 串联多个分句，中文宜按意群断句，一句一事。
3. **动词优先、少用名词化**：英文倾向用抽象名词短语（如 "the use of domestic space"）作主语，中文可转回动作性表达。
4. **调整语序适应中文逻辑**：原因／条件／让步在英文中常后置或嵌入，中文习惯前置，按中文语序重组。
5. **节制英文标点习惯**：英文用破折号补充说明、用括号插注，中文里宜改用独立短句或引号。
6. 判断标准：**把译文读出来，像不像一个中国学者说的话**。不像，就重写。

### 7. 输出排版规范（版式）

翻译产出（中间 Markdown 与最终 PDF/DOCX）须遵守以下三条：

1. **参考文献一条一行**：文末参考文献列表中，每条文献单独占一行／一段，下一条必须另起一行，不得把多条连续排在同一段。
2. **正文段落首行缩进**：中文惯例缩进 2 字符。Markdown 中无需手工敲空格（由转换器统一设置），但最终 PDF/DOCX 必须设置段首缩进。引用块、标题、图表标题、参考文献条目通常不缩进。
3. **文内引文按原文版式**：原文以整段引文（缩进引文／独立引文段落）呈现的内容，译文须保持其版式特征——**居中并改为斜体**。Markdown 中用 `>` 块引用表示，最终输出时该段居中、斜体。

### 8. 逐步积累术语库

`references/glossary.md` 是持续扩充的活文档。翻译过程中：

- 遇到确认无误的新术语，追加到术语库，并填「依据」栏
- 修改既有译法时，记录修订原因
- 拿不准就写「待核实」，把原文附在译文后

## 工作流程

### 翻译前
1. 读 `references/glossary.md`，浏览已有术语
2. 通读全文，列出出现的所有地名、遗址名、器物名、专有术语
3. 对不熟悉的词先查证（工具书、期刊既有译法、机构译名表）

### 翻译中
- 专有名词逐项对照术语库处理
- 中国遗址名逐个查证中文原名
- 外国遗址名按惯例译名 + 括号外文原名
- 按第 6 节拆分长定语、断句，边译边用中文语序重组

### 翻译后（自检清单）
- [ ] 每个遗址名是否已核实／附原文
- [ ] 器物名是否使用学界通用译名
- [ ] 有无猜译、硬译的专有名词（若有，已加括号原文）
- [ ] 该保留原文的专有名词（如 `de facto refuse`）是否被误译
- [ ] 是否还有英文式超长定语、一逗到底的复合长句
- [ ] 译文读起来是否像中国学者写的，不像就重写
- [ ] 新确认的术语是否已加入术语库，并填了依据
- [ ] 参考文献是否每条一行
- [ ] 正文段落是否已设置首行缩进
- [ ] 文内引文是否居中并斜体

## 配套

- 中文行文的去翻译腔与中英文混排，可另配通用写作类 skill（如 `fix-chinese`）；本 skill 不内置该类规则。
- 需要著录注释时，配 `kaogu-citation-format`。

## 边界

- 术语库不是权威标准。标「通行」的条目反映常见译法，不一定唯一正确；标「待核实」的条目尤其需要按你的文本再判断。
- 本 skill 不判断史实与文献内容，只处理译名与行文。
